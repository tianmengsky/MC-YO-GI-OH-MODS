# 对局赛制页：去掉“私人麦克风房间”，改默认规则

日期：2026-10-17。改动在 `addon/` 源码；已打成 0.6.31 整合包，未部署到任何实例。

## 目标与结果

| 需求 | 结果 |
| --- | --- |
| 去掉“私人麦克风房间”这一行 | 已去掉，界面只剩 取消投降 / 自由移动 / 训练模式 三行，面板同步缩短一行 23 px |
| “取消投降”默认关闭 | 默认 `false`：进入页面的第一眼是“关闭”，此时投降不再被锁 |
| “自由移动”默认开启 | 默认 `true`：开局不再把双方钉在各自那排 |

## 这一页是谁画的

- 页面本体是原 `yugioh` 模组的 `com.kiki.yugioh.client.screen.MatchFormatScreen`（标题“对局赛制”、副标题“对阵决斗AI”，1 局 / 3 局 / 5 局三行）。
- “星星对决 + 四行开关”是 `yugioh-interaction-fix` 的 `MatchFormatScreenRuleMixin` 用 Mixin 叠上去的：行号固定为 `赛制选项数+1 .. +4`，依次是 取消投降、自由移动、私人麦克风房间、训练模式；点击同理由该 Mixin 按行号接住。因此不能“删掉一个控件”，只能改行布局。
- “私人麦克风房间”功能本身早已被附属包禁掉（`VoiceRoomMixin` 拦住建/退房间，`ClientDuelRulesMixin` 把开关钉死为关），所以那一行此前是个点不动的“关闭”，去掉它不损失功能。

## 实现方式（4 个 Mixin）

| 文件 | 作用 |
| --- | --- |
| `mixin/MatchFormatScreenLayoutMixin.java`（新） | 注入 `rowTop` 返回值：麦克风行之后的每一行整体上移一个 23 px 行距，于是“训练模式”正好落在原来麦克风行的位置；由于 fix 先画麦克风行、后画训练模式行，最终只看得见训练模式。不依赖两个模组 Mixin 的应用顺序。 |
| `mixin/FormatPromptExtraMixin.java`（新） | `panelHeight` 减 23 px，面板与底部“按ESC稍后再做选择”一起上移，不会留一行空白。 |
| `mixin/ClientDuelRulesMixin.java`（改） | `resetForPrompt` 结束时把 `取消投降` 置 false、`自由移动` 置 true；点击被折叠的那一格改走 `flipTraining`，否则点击会被原麦克风行截获。 |
| `mixin/DuelRulesOffersMixin.java`（新） | 玩家没点任何开关就直接选赛制时，服务端原本回落到 `DuelRules.Rules.DEFAULT`（禁止投降、固定站位），与界面矛盾；这里把回落值换成 `(false, true, false, false)`，与页面默认值、与附属包 GameTest 里一直在用的组合一致。 |

注册在 `src/main/resources/yugioh_mdpro_addon.mixins.json`：`DuelRulesOffersMixin` 进公共列表，另两个进 client 列表。

## 验证

- `gradle -p addon --no-daemon --offline compileJava`：通过。
- `gradle -p addon --no-daemon --offline runGameTestServer`：`All 16 required tests passed`。其中 `LegacyFeatureGameTests.nativeTrainingAndRuleIsolation` 新增一条断言，直接检查 `DuelRulesOffers.rulesFor(null)` 为“可投降 / 可自由移动 / 无麦克风房间 / 非训练”，覆盖服务端回落值。
- `gradle -p addon --no-daemon --offline -PcatalogSmoke runClient`（固定在 `run-catalog`，mods 为空，避免已部署整合包盖住开发类）：`generated/visual-smoke-result.txt` 为 PASS；`generated/feature-smoke-format.png` 为改后实拍，可见三行开关、默认 关闭 / 开启 / 关闭、面板与底部提示之间无空行。`ClientVisualSmoke` 的 stage 2 也新增断言：训练行与被折叠行的 `rowTop` 必须相同且都能命中同一矩形。
